# Windrise 长上下文测试用例集

在同一会话里**按顺序连续提问**。建议每个场景使用**新会话**，避免互相干扰。

每轮回答后检查：
1. **故障码**是否正确（是否仍停留在上一轮）
2. **风场/机位**是否匹配
3. 是否出现错误拼接，如：`已理解您的问题为：故障码5...`

---

## 场景 A：故障串话（核心问题复现）

| 步骤 | 输入 | 期望结果 | 不应出现 |
|------|------|----------|----------|
| A1 | 同发风场A32号风机 SS-4刹车存储继电器 | 故障码 5，SS-4刹车存储继电器未复位 | — |
| A2 | 同发风场A32号风机主PLC检测到从PLC通讯错误 | 故障码 272，4条PLC检查步骤，证据命中 | 故障码5、SS-4 |
| A3 | 八面风场ZC05风机 功率过低切出 | 故障码 70029，发电状态下功率过低，风场八面 | 故障码5、同发、SS-4 |
| A4 | 故障码5922是什么 | 5922 小风正常停机（可多条机型记录） | 272、70029、SS-4 |
| A5 | 1200010 | 1200010 SC_风速低于限值 | 5922、5、272 |

## 建议测试顺序

| 优先级 | 场景 | 说明 |
|--------|------|------|
| P0 | A、B、H | 覆盖已遇到的串话问题 |
| P0 | L、M、P | **定位后再报症状（本次修复）** |
| P1 | C、D、E | 范围补充与切换 |
| P1 | N、O、R | 型号查询与同机位换症状 |
| P2 | F、G、I、J、Q、S | 路由与边界 |
