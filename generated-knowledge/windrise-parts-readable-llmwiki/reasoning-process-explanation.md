# 风电部件故障证据链推理过程说明

## 1. 页面目标

该页面用于把风电部件故障处理报告中的内容整理成可播放的推理图谱。它不是只展示静态知识点，而是把“故障现象、原因、排查、证据、处理、验证、预防”组织成证据链，让用户能够看到每一步推理走到了哪个节点。

当前页面支持 4 个故障案例：

- 变流器 IGBT 板卡故障
- 偏航液压系统压力异常
- 主轴轴承复合磨损故障
- 发电机绕组端温度高/跳变

每个案例都可以围绕 5 类问题进行专项推理。

## 2. 图谱结构

图谱按照从左到右的证据链泳道排布：

| 泳道 | 含义 |
| --- | --- |
| 根因 | 导致故障的基础原因、管理缺陷或已排除的可疑原因 |
| 中间失效 | 根因引发的中间物理过程或部件状态变化 |
| 故障 | 当前选中的故障案例 |
| 证据/表现 | 报警、测量数据、现场现象、诊断步骤和支持证据 |
| 处理 | 临时措施、永久处理或更换修复动作 |
| 验证/预防 | 处理后的验证结果、预防复发措施 |

图上的节点表示知识实体，例如“隐蔽阻尼缓冲器堵塞”“偏航回路液压油流量受限”“151bar 降至 27bar，150bar 恢复约 300s”。

图上的边表示实体之间的推理关系，例如：

- 导致
- 触发
- 排查
- 确认
- 证据
- 处理
- 验证
- 预防

## 3. 推理链播放方式

点击“播放证据链”后，系统会执行以下步骤：

1. 根据输入问题识别故障案例。
2. 根据问题内容识别推理意图。
3. 先从故障节点反向寻找能够收敛到故障的根因链。
4. 再按问题意图补充排查、证据、处置、验证或预防关系。
5. 按“核心路径优先、补充证据随后”的顺序生成证据链。
5. 动画逐步点亮当前边、当前节点和右侧步骤。

播放时：

- 蓝色高亮边表示当前正在推理的关系。
- 蓝色发光节点表示当前到达的证据链节点。
- 右侧步骤列表同步滚动，显示当前阶段、关系动作和节点流向。
- 进度条表示当前证据链已经播放到第几步。

## 4. 五类推理问题

页面右侧提供 5 个固定问题入口。每个入口对应不同的推理目标，因此生成的证据链也不同。

### 4.1 原因链推理

问题示例：

> 偏航液压系统压力异常是什么原因导致？根因链是什么？

推理目标：

从根因出发，展示它如何逐步导致故障或故障表现。

链路组织方式：

先沿 `导致/触发` 关系寻找从根因到故障的主路径，再补充故障表现和关键证据。

主要使用关系：

- 导致
- 触发
- 表现为
- 升级为

示例链路：

```text
隐蔽阻尼缓冲器堵塞
→ 偏航回路液压油流量受限
→ 偏航回路建压缓慢
→ 偏航回路压力恢复缓慢
→ 偏航液压系统压力异常
```

### 4.2 排查路径推理

问题示例：

> 偏航液压系统压力异常如何排查定位？排查步骤是什么？

推理目标：

展示从故障出发，应先检查什么、如何排除错误原因、最终如何定位真实原因。

链路组织方式：

优先展示从故障出发的排查入口；如果某个案例没有显式排查步骤，则退化为诊断证据入口。随后展示排查结果、排除项或确认项，最后回扣根因链。

主要使用关系：

- 排查
- 确认
- 排除
- 早期诊断
- 证据

示例链路：

```text
偏航液压系统压力异常
→ 主回路压力和液压泵电流测试
→ 主回路压力 280±10bar、液压泵电流 5.2A
→ 排除主回路故障
→ 咨询厂家并检查图纸未标注阻尼缓冲器
→ 确认隐蔽阻尼缓冲器堵塞
```

### 4.3 证据支持推理

问题示例：

> 偏航液压系统压力异常有哪些证据支持？证据链是什么？

推理目标：

展示哪些报警、测量值、现场现象或处理结果能够支持故障判断。

链路组织方式：

先展示故障现象，再展示测量数据、报警、诊断结论和处理后佐证，最后用因果链解释这些证据为什么支持判断。

主要使用关系：

- 证据
- 佐证
- 确认
- 表现为
- 导致

示例链路：

```text
偏航液压系统压力异常
→ 151bar 降至 27bar，150bar 恢复约 300s
→ 偏航回路压力恢复缓慢
→ 清理后偏航回路压力 11s 升至约 153bar
→ 支持阻尼缓冲器堵塞判断
```

### 4.4 处理验证推理

问题示例：

> 偏航液压系统压力异常怎么处理并验证效果？

推理目标：

展示采取了什么处理措施，以及处理后如何证明故障被消除。

链路组织方式：

先展示临时措施和永久处理，再展示处理动作连接到的验证结果；最后补充故障依据，形成“为什么处理、怎么处理、如何确认”的闭环。

主要使用关系：

- 临时缓解
- 处理
- 验证
- 佐证
- 证据

示例链路：

```text
偏航液压系统压力异常
→ 临时调整缓冲器开度恢复压力
→ 清理并更换改进型 φ5mm 缓冲器
→ 清理后 11s 升至 153bar 且无新增告警
```

### 4.5 预防复发推理

问题示例：

> 偏航液压系统压力异常如何预防复发？

推理目标：

从故障和根因反推维护策略，说明如何防止同类问题再次发生。

链路组织方式：

先展示预防策略，再展示这些策略阻断了哪些根因或风险；最后回扣原始根因链，说明预防措施对应的是哪一段失效机理。

主要使用关系：

- 预防
- 防止
- 导致
- 触发

示例链路：

```text
偏航液压系统压力异常
→ 更新液压图纸并标注隐蔽缓冲器
→ 缓冲器纳入季度检查、清洁和性能测试
→ 防止液压图纸缺失和隐蔽缓冲器堵塞再次引发故障
```

## 5. 自由提问如何匹配推理类型

除了点击右侧 5 个问题按钮，用户也可以在顶部输入框直接提问。系统会根据关键词判断问题类型：

| 关键词 | 匹配问题 |
| --- | --- |
| 原因、导致、根因、为什么、因果 | 原因链推理 |
| 排查、定位、检查、诊断、怎么查 | 排查路径推理 |
| 证据、支持、数据、现象、表现、报警 | 证据支持推理 |
| 处理、修复、更换、解决、验证、效果 | 处理验证推理 |
| 预防、复发、防止、避免 | 预防复发推理 |

系统会同时识别故障关键词，例如：

- 偏航、液压
- IGBT、变流
- 主轴、轴承
- 绕组、温度

因此用户可以直接问：

```text
主轴轴承复合磨损故障如何预防复发？
```

页面会自动选择主轴轴承案例，并播放预防复发证据链。

## 6. 以偏航液压系统压力异常为例

完整推理可以理解为以下闭环：

```text
根因：
隐蔽阻尼缓冲器堵塞

中间过程：
偏航回路液压油流量受限
→ 偏航回路建压缓慢

故障表现：
偏航回路压力恢复缓慢
→ 151bar 降至 27bar，150bar 恢复约 300s

排查证据：
主回路压力和液压泵电流测试正常
→ 电磁换向阀、截止阀、单向阀、定差节流阀等可疑项被排查
→ 咨询厂家并检查图纸，确认隐蔽阻尼缓冲器问题

处理：
临时调整缓冲器开度
→ 清理并更换改进型 φ5mm 缓冲器

验证：
清理后 11s 升至 153bar 且无新增告警

预防：
更新液压图纸
→ 将缓冲器纳入季度检查、清洁和性能测试
```

这条链路说明了页面推理的核心逻辑：不是只回答“是什么故障”，而是把“为什么发生、怎么查出来、凭什么确认、怎么处理、如何防止复发”串成一条可视化证据链。
