## 核心因果链

### 1. 变流器 IGBT 板卡故障

来源：`2MW风电机组变流器IGBT板卡故障的分析及解决方案_林延填.pdf`

推理链：

`电网电压波动 / 粉尘盐雾潮湿 / 塔底散热不足`
→ `IGBT 驱动板滤波电容烧坏、短路或接触不良、器件高温`
→ `INU/ISU 模块故障、变流器高温停机、跳闸`
→ `更换 IGBT 驱动板，改善散热、防潮、滤网清理和温度监控`

关键证据：

- 报警包括 `ISU SC`、`INU SC 1V`、`INU 2W SC`。
- K8 接触器无法吸合，温度传感器未见异常，打磨 K8 接触器后恢复。
- 改造后变流器正常运行温度下降约 15 摄氏度，一年期 7 台机组 IGBT 故障降至 2 次。

建议处理：

- 备足 IGBT 驱动板备件。
- 定期清理或更换变流器通风滤网。
- 潮湿天气加强巡检、防潮，必要时开启除湿设备。
- 增设引流外罩、增大散热电机功率、增加工业风扇、延伸散热管道。
- 加强 IGBT 板卡温度监控，调整风扇温控参数。

### 2. 偏航液压系统压力异常

来源：`砀山风电场15#风电机组偏航液压系统压力异常故障处理全流程解析_孙士雪.pdf`

推理链：

`图纸未标注的隐蔽阻尼缓冲器堵塞`
→ `偏航回路液压油流量受限`
→ `偏航结束后压力恢复缓慢、压力异常波动、液压站欠压`
→ `清理柱塞孔/缓冲器并更换改进型缓冲器`

关键证据：

- 手动释放偏航刹车时压力从 151 bar 急降至 27 bar。
- 恢复刹车后压力恢复至 135 bar 需 120 s，至 145 bar 需 150 s，至 150 bar 约需 300 s；正常应小于 30 s。
- 主回路压力 280±10 bar、液压泵电流 5.2 A，主回路基本正常。
- 清理隐蔽阻尼缓冲器相关孔洞后，偏航回路压力 11 s 上升至约 153 bar。

建议处理：

- 临时：精细调整缓冲器开度，使偏航回路压力恢复正常范围。
- 永久：改进缓冲器结构，适当增大孔径，优化内部流道，采用改进型 φ5 mm 缓冲器。
- 预防：更新液压图纸，把所有阻尼缓冲器位置、规格、技术要求标清。
- 维护：将缓冲器检查纳入季度维护，定期清洁、保养和性能测试。

口径说明：原始报告中液压泵电流为 5.2 A；后续问题串汇总 PDF 中对应问题写为 2.5 A。图谱按原始报告口径保留 5.2 A，问答题库按问题串口径命中 2.5 A；对外展示前应统一口径。

### 3. 主轴轴承复合磨损故障

来源：`风电机组主轴的检修维护及故障分析与应对策略_卢祥林.pdf`

推理链：

`高海拔大温差 + 强湍流载荷 + 润滑污染 + 安装同轴度偏差 + 密封老化`
→ `油膜破裂、三体磨损、微裂纹扩展`
→ `内圈剥落、外圈剥落、滚动体凹坑、周期性冲击振动`
→ `停机隔离、清洗润滑腔、更换轴承、密封和润滑系统升级、在线监测`

关键证据：

- 振动速度有效值 4.8 mm/s，正常值 ≤2.8 mm/s。
- 峭度 8.7，正常值 ≤4。
- BPFI 幅值占比 12%，BSF 谐波幅值较基准增长 8 倍。
- 内圈剥落 3.2 mm×1.5 mm，外圈剥落面积 15%，滚动体凹坑平均 0.8 mm。
- 润滑脂金属磨屑 1200 ppm，允许值 ≤150 ppm。
- 轴承座与主轴同轴度偏差 0.15 mm，标准 ≤0.05 mm。

建议处理：

- 立即停机并更换全套轴承。
- 主轴轴颈抛光修复，粗糙度控制在 Ra0.8 μm 以内。
- 排空污染润滑脂，清洗轴承腔体，增加在线过滤装置。
- 对剥落面积超过 10% 的轴承组件整体更换。
- 单唇口密封升级为迷宫式 + 磁性流体复合密封。
- 加装振动在线监测系统和油液颗粒趋势监测。
- 维护策略上缩短油液分析周期，建立关键部件一机一档。

### 4. 发电机绕组端温度高/跳变

来源：`风电机组发电机绕组端温度高故障分析及处理_张新旺.pdf`

推理链：

`温度信号电缆屏蔽差、屏蔽层未良好接地、布线不规范、发电机强电磁场耦合`
→ `Pt100 模拟量测温信号受电磁干扰`
→ `绕组温度值 70-135 摄氏度跳变、并网后波动随负荷增大、误报温度高故障`
→ `检查 Pt100 阻值、倒换 PLC 通道、检查接地、重新敷设/更换屏蔽信号电缆、必要时切换备用传感器`

关键证据：

- 1V 相温度在 70-135 摄氏度之间跳变，曲线不平滑，叠加高次谐波和随机粗大干扰。
- 停机或待机时温度稳定；并网后连续波动，且负荷越大干扰幅值越大。
- 温度采集模块通道倒换后，PLC 模块判断正常。
- 信号电缆两端屏蔽层未接地，接线盒接地端子与导轨未接通。
- 更换屏蔽信号电缆后，除 2V 相外温度跳变幅值和频率显著降低；2V 相切换备用传感器后稳定。

建议处理：

- 用 Pt100 经验公式校核传感器阻值，偏差超过 1 Ω 更换传感器。
- 与正常温度传感器倒换 PLC 模块通道，排除采集模块故障。
- 检查信号接地，确保屏蔽层按工艺要求接地。
- 重新敷设发电机温度传感器接线盒至机舱控制柜的信号电缆。
- 对模拟量信号按屏蔽、滤波、布线、接地四项原则处理。

## 细化推理流程模板

### 变流器 IGBT 板卡故障

1. 命中故障：变流器 IGBT 板卡故障。
2. 原因链：
   电网电压波动、粉尘盐雾潮湿、塔底散热不足。
3. 诊断证据：
   ISU SC / INU SC 故障报文；K8 接触器无法吸合；散热风扇持续启动；温度传感器未见异常。
4. 临时处理：
   更换对应相 IGBT 驱动板，恢复预充电实验和零速实验。
5. 永久处理：
   清理或更换通风滤网，防潮巡检，增设引流外罩、工业风扇、散热管道，调整风扇温控参数。
6. 效果验证：
   改造后运行温度下降约 15 摄氏度，IGBT 故障次数下降。

### 偏航液压系统压力异常

1. 命中故障：偏航液压系统压力异常。
2. 原因链：
   图纸未标注的隐蔽阻尼缓冲器堵塞。
3. 排查步骤：
   主回路压力和液压泵电流测试；换向阀调换；截止阀、单向阀、定差节流阀排查；咨询厂家并检查隐蔽阻尼缓冲器。
4. 诊断证据：
   手动释放偏航刹车压力 151 bar 降至 27 bar；恢复至 150 bar 约需 300 s；主回路 280±10 bar、液压泵电流 5.2 A；清理后 11 s 升至约 153 bar。
5. 临时处理：
   调整缓冲器开度，恢复偏航回路压力。
6. 永久处理：
   更换改进型 φ5 mm 缓冲器，优化孔径和内部流道。
7. 预防复发：
   更新液压图纸，标注隐蔽缓冲器；纳入季度检查、清洁和性能测试。

### 主轴轴承复合磨损故障

1. 命中故障：主轴轴承复合磨损故障。
2. 原因链：
   高海拔大温差、强湍流载荷、润滑污染、同轴度偏差、密封老化共同作用。
3. 诊断证据：
   振动 4.8 mm/s；峭度 8.7；BPFI 增强；内圈剥落 3.2 mm×1.5 mm；外圈剥落 15%；润滑脂金属磨屑 1200 ppm；同轴度偏差 0.15 mm；D4 严重损伤阶段。
4. 临时处理：
   立即停机隔离，排空污染润滑脂，清洗轴承腔体。
5. 永久处理：
   更换全套轴承，主轴轴颈抛光修复至 Ra0.8 μm 以内，密封升级，润滑系统加装在线过滤。
6. 预防复发：
   加装振动在线监测和油液颗粒趋势监测，建立关键部件一机一档。

### 发电机绕组端温度高/跳变

1. 命中故障：发电机绕组端温度高/跳变。
2. 原因链：
   发电机强电磁场、外部动力电缆干扰、屏蔽层未良好接地、布线不规范。
3. 排查步骤：
   用 Pt100 公式校核阻值；倒换 PLC 模块通道；检查屏蔽层和接地端子；更换屏蔽信号电缆；必要时切换备用传感器。
4. 诊断证据：
   1V 相温度 70-135 摄氏度跳变；停机稳定、并网后随负荷增大波动；通道倒换后 PLC 模块正常。
5. 永久处理：
   重新敷设屏蔽信号电缆，屏蔽层按工艺接地，接通接地端子与导轨，2V 相切换备用温度传感器。
6. 预防复发：
   对模拟量信号按屏蔽、滤波、布线、接地四项原则治理。

## 多跳证据链

### 变流器 IGBT 板卡故障多跳

- `电网电压波动 -> IGBT驱动板内部滤波电容烧坏 -> 变流器IGBT板卡故障 -> INU/ISU模块故障 -> 更换IGBT驱动板 -> 预充电实验和零速实验正常`
- `粉尘盐雾潮湿 -> 驱动板短路或接触不良 -> 变流器IGBT板卡故障 -> 变流器跳闸/总故障/转子侧故障触发`
- `塔底散热不足 -> 塔底热气聚集和环境温度升高 -> 变流器高温停机 -> 改善塔底散热 -> 运行温度下降约15摄氏度`

### 偏航液压系统压力异常多跳

- `液压图纸未标注隐蔽阻尼缓冲器 -> 常规排查未覆盖隐蔽元件 -> 厂家沟通和隐蔽缓冲器检查 -> 阻尼缓冲器堵塞`
- `阻尼缓冲器堵塞 -> 偏航回路液压油流量受限 -> 偏航回路建压缓慢 -> 偏航回路压力恢复缓慢 -> 151bar降至27bar且恢复到150bar约300s`
- `主回路测试 -> 主回路压力280±10bar、液压泵电流5.2A -> 排除主回路故障`
- `清理/更换改进型缓冲器 -> 清理后11s升至153bar且无新增告警 -> 更新图纸和季度维护 -> 预防复发`

### 主轴轴承复合磨损故障多跳

- `密封结构失效 -> 污染物侵入 -> 润滑脂劣化和油膜不足 -> 金属直接接触 -> 微观点蚀扩展 -> 宏观剥落和二次损伤 -> 主轴轴承复合磨损`
- `强湍流载荷 -> 微裂纹/点蚀扩展 -> 内圈剥落、外圈剥落、滚动体凹坑 -> 周期性冲击振动和高频共振`
- `同轴度偏差 -> 附加偏心载荷 -> 金属直接接触 -> 三体磨损`
- `主轴轴承复合磨损 -> 继续运行保持架断裂风险升高 -> 立即停机隔离 -> 更换全套轴承和润滑密封改造`
- `振动在线监测 + 油液颗粒趋势监测 -> 早期诊断微观点蚀 -> MTBF从1800h延长至3500h`

### 发电机绕组温度跳变多跳

- `屏蔽层未良好接地 -> 温度信号电缆屏蔽层两端未接地 -> 模拟量测温信号被电磁耦合 -> 温度示值误差和测量失真 -> 绕组温度70-135摄氏度跳变 -> 误报温度高故障`
- `电磁干扰 -> 模拟量测温信号被电磁耦合 -> 并网后温度波动随负荷增大`
- `倒换PLC模块通道 -> PLC模块正常 -> 排除PLC采集模块故障`
- `更换屏蔽信号电缆 -> 缩小干扰范围 -> 检查接地/切换备用传感器 -> 温度稳定`
