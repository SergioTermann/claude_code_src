# 知识图谱推理正确性检查

检查对象：

- `curated-parts-graph.json`：人工清洗版图谱，建议用于客户展示和现场问答推理。
- `graph/knowledge-graph.json`：自动抽取全量图谱，只适合作为候选关系池。
- `graph/reasoning-graph.json`：自动抽取推理子图，只适合作为候选推理边。

## 检查结论

清洗版图谱的偏航液压系统压力异常推理主链条是正确的。

现场链路应理解为：

```text
偏航压力异常 / 液压站欠压
→ 释放和恢复刹车后确认压力恢复很慢
→ 主回路压力和泵电流正常，排除主回路
→ 调换电磁换向阀后仍慢，排除换向阀
→ 检查截止阀、单向阀、定差节流阀后仍慢，逐项排除
→ 厂家确认单向阀与定差节流阀之间还有隐蔽阻尼缓冲器
→ 清理阻尼缓冲器小孔后，压力 11s 升至约 153bar
→ 根因闭环：隐蔽阻尼缓冲器堵塞导致偏航回路建压慢
```

程序校验结果：

- 关键推理边：14/14 通过。
- 已排除部件误判为根因：0 项。
- 临时处理、永久处理、预防措施链路均存在。

## 正确的推理关系

### 根因链

```text
隐蔽阻尼缓冲器堵塞
→ 偏航回路液压油流量受限
→ 偏航回路建压缓慢
→ 偏航回路压力恢复缓慢 / 液压站持续欠压报警
→ 偏航液压系统压力异常
```

### 排除链

```text
主回路压力和液压泵电流测试
→ 排除主回路故障

电磁换向阀调换排查
→ 排除电磁换向阀故障

检查截止阀 10.2
→ 排除截止阀堵塞

检查单向阀 9.3
→ 排除单向阀堵塞

检查定差节流阀 22.1
→ 排除定差节流阀堵塞
```

### 验证链

```text
清理隐蔽阻尼缓冲器孔洞
→ 偏航回路压力 11s 升至约 153bar
→ HMI 无新增告警
→ 支持“隐蔽阻尼缓冲器堵塞”判断
```

### 处理和预防链

```text
临时：调整缓冲器开度，恢复压力
永久：更换改进型 φ5mm 缓冲器，优化孔径和内部流道
预防：更新液压图纸，将缓冲器纳入季度检查、清洁和性能测试
```

## 需要注意的问题

### 1. 自动抽取图谱噪声较大

`graph/knowledge-graph.json` 和 `graph/reasoning-graph.json` 中有大量 PDF 双栏文本串行造成的半句节点，例如把跨栏文字拼成一个节点。这类节点不能直接作为现场推理结论。

建议：

- 客户展示优先使用 `curated-parts-graph.json`。
- 自动图谱只作为候选关系池，不能直接说“推理已经完全正确”。

### 2. 电流值存在资料口径差异

原始报告 `砀山风电场15#风电机组偏航液压系统压力异常故障处理全流程解析_孙士雪.pdf` 中，主回路测试记录为：

```text
主回路压力 280±10bar，液压泵电流 5.2A
```

后续问题串汇总 PDF 中，对应问题写成：

```text
主回路压力 280bar，液压泵电流 2.5A
```

因此：

- 知识图谱按原始报告口径使用 `5.2A`，不是抽取错误。
- 问答测试题库按问题串口径使用 `2.5A`。
- 对外展示时应统一口径，避免同一场景同时出现 `5.2A` 和 `2.5A`。

## 最终判断

清洗版知识图谱的推理方向正确，可以用于现场排查演示；自动抽取版图谱需要继续过滤噪声后再作为正式推理图谱使用。
