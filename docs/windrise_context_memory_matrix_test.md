# Windrise 上下文记忆与现场反馈测试记录

测试时间：2026-06-23  
测试对象：Windrise Web `/api/chat`  
测试目的：验证系统在“初始问题 -> 现场反馈”两轮对话中，是否能保持上下文，并继续给出明确的下一步现场动作。

## 测试结论

本轮共测试 11 类常见风机现场问题：

- 通信掉线
- 水冷压力低
- 传感器跳变
- 主轴承异常
- 电网并网异常
- SCADA 伴随告警
- 变桨 24V 反馈丢失
- 发电机轴承温度高
- 齿轮箱油温高
- 安全链断开
- 雷击浪涌/接地异常

当前结果：11 类场景均能在第二轮现场反馈后，沿着上一轮判断继续收敛，不再泛化成大段资料或无关建议。

## 详细测试结果

### 1. 通信掉线

**第一轮问题**

```text
风机通信掉线怎么办
```

**系统回答摘要**

```text
最可能判断：先按机组现场通讯中断处理。
现场验证：先看掉线的是单台设备还是一整段通讯都不正常。
做完反馈：掉线设备、通讯灯状态、总线错误计数。
```

**第二轮现场反馈**

```text
只有一台设备掉线，通讯灯灭，总线错误计数没有变化
```

**系统回答摘要**

```text
最可能判断：主干通讯先不扩大查，问题集中在这台掉线设备本身。
现场验证：测这台设备的 24V 供电，再重新插紧通讯接插件。
做完反馈：24V 实测值、接插件状态、重插后通讯灯是否恢复。
```

### 2. 水冷压力低

**第一轮问题**

```text
水冷回路压力低下一步查什么
```

**系统回答摘要**

```text
最可能判断：先按水冷回路流量、压力或散热能力不足处理。
现场验证：先确认水泵运行反馈和冷却液液位，不要先改参数。
做完反馈：水泵是否运行、液位是否正常、当前压力/流量值。
```

**第二轮现场反馈**

```text
水泵运行，液位正常，压力还是低
```

**系统回答摘要**

```text
最可能判断：水泵和液位已基本排除，下一处最可能是过滤器堵塞或阀门开度不足。
现场验证：先查水冷过滤器压差和进出水阀门开度，不要先拆水泵。
做完反馈：过滤器压差、阀门开度、调整后的压力/流量值。
```

### 3. 传感器跳变

**第一轮问题**

```text
风机传感器测量值跳变怎么处理
```

**系统回答摘要**

```text
最可能判断：先按传感器测量回路异常处理。
现场验证：用独立仪表或相邻测点做一次交叉比对。
做完反馈：现场实测值、SCADA/HMI 显示值、传感器供电或回路电阻。
```

**第二轮现场反馈**

```text
现场表稳定，但是HMI显示值还在跳变
```

**系统回答摘要**

```text
最可能判断：真实工况先放过，问题集中在传感器测量回路。
现场验证：先量传感器供电电压和回路电阻，再检查屏蔽接地与采集通道端子。
做完反馈：传感器供电电压、回路电阻、屏蔽接地状态、重插端子后显示是否稳定。
```

### 4. 主轴承异常

**第一轮问题**

```text
主轴承温度高并且低频振动升高，下一步查什么
```

**系统回答摘要**

```text
最可能判断：先按主轴轴承润滑、载荷或密封失效处理。
现场验证：先看主轴承温度趋势和低频振动，不要只按单点告警判断。
做完反馈：轴承温度、振动频谱或趋势、油脂状态。
```

**第二轮现场反馈**

```text
温度趋势升高，油脂里看到金属粉
```

**系统回答摘要**

```text
最可能判断：主轴承已经从一般告警转为磨损风险，不能只复位观察。
现场验证：先停机取样复核油脂金属粉，并安排主轴承振动频谱复测。
做完反馈：油脂复样结果、低频振动频谱、主轴承温度趋势。
```

### 5. 电网并网异常

**第一轮问题**

```text
风机并网失败，电网电压异常下一步查什么
```

**系统回答摘要**

```text
最可能判断：先按电网、箱变或并网保护异常处理。
现场验证：先核对三相电压频率和断路器/接触器反馈。
做完反馈：三相电压频率、断路器反馈、伴随保护记录。
```

**第二轮现场反馈**

```text
三相电压频率正常，但是接触器反馈不一致
```

**系统回答摘要**

```text
最可能判断：外部电网先放过，问题集中在并网执行反馈回路。
现场验证：先查并网接触器或断路器辅助触点，再核对反馈线到 PLC 输入点。
做完反馈：接触器/断路器实际位置、辅助触点状态、PLC 输入点状态。
```

### 6. SCADA 伴随告警

**第一轮问题**

```text
SCADA趋势和伴随告警怎么判断
```

**系统回答摘要**

```text
最可能判断：先按 SCADA 数据质量、报警关联或工况边界异常处理。
现场验证：先导出报警前后趋势和伴随告警，按时间线对齐现场动作。
做完反馈：报警时间、前后趋势、伴随告警列表。
```

**第二轮现场反馈**

```text
只在状态切换时报警，现场设备动作正常
```

**系统回答摘要**

```text
最可能判断：设备本体先放过，问题更像状态量切换或阈值边界引起的误报警。
现场验证：先对齐报警时间、状态切换时间和阈值触发点，只看这三项。
做完反馈：报警时间、状态切换时间、触发阈值或状态量。
```

### 7. 变桨 24V 反馈丢失

**第一轮问题**

```text
变桨24V主电源开关反馈丢失怎么处理
```

**系统回答摘要**

```text
最可能判断：先按变桨 24V 控制电源或开关反馈丢失处理。
现场验证：先量变桨 24V 控制电源输出，再核对主电源开关实际位置和 PLC 反馈。
做完反馈：24V 实测值、主电源开关位置、辅助触点或 PLC 输入点状态。
```

**第二轮现场反馈**

```text
24V电压正常，但是主电源开关反馈还是丢失
```

**系统回答摘要**

```text
最可能判断：变桨控制电源先放过，问题集中在开关辅助触点或 PLC 反馈回路。
现场验证：先查 24V 主电源开关辅助触点，再量辅助触点到 PLC 输入点的通断。
做完反馈：24V 实测值、开关实际位置、辅助触点状态、PLC 输入点状态。
```

### 8. 发电机轴承温度高

**第一轮问题**

```text
发电机轴承温度高下一步查什么
```

**系统回答摘要**

```text
最可能判断：先按发电机轴承温度、润滑或冷却异常处理。
现场验证：先对齐发电机轴承温度趋势和振动趋势，再看冷却通风是否正常。
做完反馈：发电机轴承温度趋势、振动趋势、冷却风道/风扇状态。
```

**第二轮现场反馈**

```text
温度高但是振动正常，冷却风扇在运行
```

**系统回答摘要**

```text
最可能判断：暂不支持发电机轴承机械损伤，先查测温和冷却通风。
现场验证：复核发电机轴承 PT100/温度探头接线和安装，再看冷却风道、风扇和滤网是否堵塞。
做完反馈：轴承温度趋势、振动趋势、测温探头状态、冷却风道/风扇状态。
```

### 9. 齿轮箱油温高

**第一轮问题**

```text
齿轮箱油温高并且滤芯压差报警怎么处理
```

**系统回答摘要**

```text
最可能判断：先按齿轮箱温升或润滑过滤异常处理。
现场验证：先确认油冷风扇或水冷是否运行，再看油位、滤芯压差和油样状态。
做完反馈：油冷运行状态、齿轮箱油位、滤芯压差、油样外观。
```

**第二轮现场反馈**

```text
油冷风扇运行正常，但是油温还是高，滤芯压差高
```

**系统回答摘要**

```text
最可能判断：齿轮箱润滑过滤阻力偏大，先按滤芯堵塞和油液污染处理。
现场验证：更换滤芯前后记录压差，并检查旧滤芯和油样是否有金属屑或乳化。
做完反馈：更换前后压差、旧滤芯状态、油样是否有金属屑或乳化。
```

### 10. 安全链断开

**第一轮问题**

```text
安全链断开下一步查什么
```

**系统回答摘要**

```text
最可能判断：先按安全链或急停保护链断开处理。
现场验证：先看急停是否复位，再从安全继电器输入端逐点找第一个断开的安全点。
做完反馈：急停状态、安全继电器状态、第一个断开的安全点。
```

**第二轮现场反馈**

```text
急停都没按下，但是安全链还是断开
```

**系统回答摘要**

```text
最可能判断：急停按钮先放过，问题集中在安全继电器或某个串联安全开关。
现场验证：从安全继电器输入端开始逐点量，找到第一个没有闭合信号的安全开关。
做完反馈：安全继电器状态、第一个断点位置、该开关现场状态。
```

### 11. 雷击浪涌/接地异常

**第一轮问题**

```text
雷雨后风机多系统报警接地异常怎么处理
```

**系统回答摘要**

```text
最可能判断：先按雷击、浪涌或接地屏蔽异常处理。
现场验证：先查 SPD 指示、24V 电源输出和电柜接地连接，判断是不是保护回路先失效。
做完反馈：SPD 指示状态、24V 输出、电柜接地连接、异常模块范围。
```

**第二轮现场反馈**

```text
雷雨后多个系统报警，SPD指示异常，接地电阻偏高
```

**系统回答摘要**

```text
最可能判断：不像单一部件故障，优先按雷击浪涌后的供电、通讯和接地保护异常处理。
现场验证：先查柜内 SPD 状态、24V 电源输出和接地排连接，再看通讯模块是否成组异常。
做完反馈：SPD 指示状态、24V 输出、电柜接地连接、异常模块范围。
```

## 本轮发现的问题

测试初期发现，以下场景的第二轮反馈曾经会进入慢模型路径，导致回答发散：

- 传感器跳变反馈后，曾出现大段知识库资料和液压场景串话。
- 主轴承反馈后，曾泛化成普通机械磨损建议。
- 电网反馈后，曾等待慢模型生成，现场动作不稳定。
- SCADA 问题中，“怎么判断”曾没有被识别为现场诊断意图。

## 已修复内容

- 将“怎么判断 / 如何判断 / 判断”纳入确定性诊断意图。
- 补齐传感器跳变的第二轮反馈规则。
- 补齐主轴承温度和油脂异常的第二轮反馈规则。
- 补齐电网正常但接触器反馈不一致的第二轮反馈规则。
- 补齐 SCADA 状态切换误报警的第二轮反馈规则。

## 当前评价

当前 11 类问题已经能稳定体现以下能力：

- 保留上一轮判断方向。
- 根据用户现场反馈切换到下一步动作。
- 不再一次性展开大清单。
- 不再输出大段原始资料。
- 输出更接近现场机械、电气工程师能直接执行的检查动作。

## 后续建议

建议继续扩展测试集，重点覆盖：

- 变桨 24V 控制电源反馈丢失
- 偏航液压压力恢复慢
- 发电机轴承温度高
- 齿轮箱油温高或滤芯压差
- 安全链断开
- 雷击、浪涌、接地异常

每个场景都建议保持同样的测试结构：

```text
第一轮：用户提出故障或下一步问题
第二轮：用户反馈一个现场结果
期望：系统给出一个最可能判断、一个现场验证动作、一个合格标准、一个反馈项
```
