# 歧义熵门控 (AEG) — 创新点与有效性实验报告（留一实测版）

> **Ambiguity-Entropy Gating**：用信息论对故障码消歧风险做**检索前**的可解释度量与主动门控。
>
> 数据：`风机故障码/fault-index.jsonl`，11,476 条有效故障记录（`code / brand / model / name`）。
> 实测脚本：`scripts/aeg-empirical-loo-experiment.py`（留一法，纯标准库，可复现）。
> 早期闭式期望版脚本 `scripts/aeg-ambiguity-entropy-experiment.py` 保留作对照。

---

## 1. 创新点

同一数字故障码在不同机型下含义不同（同码异义）。现有做法（含本系统 L2）是**被动**的：检索时结合机型、范围不明才提示。**AEG** 在**检索之前**对每个故障码 `c` 计算香农歧义熵

```
H(c) = − Σ pᵢ · log₂ pᵢ
```

（`pᵢ` 为该码第 i 种含义的频率占比）。`H=0`（单义）直接作答不打扰；`H` 越大→跨机型歧义越强→**检索前主动追问机型**；以阈值 `τ` 排序门控，得到"追问成本 ↔ 误命中"的可调工作点。**把消歧从检索后补救提前为检索前、可量化、可设阈值的主动风控。**

---

## 2. 实验方法：留一法真实泛化误差

**关键改进**：不再用闭式期望（`miss=1−max pᵢ`），而是**留一法（leave-one-out）实测**——把每条故障记录当作一次真实查询，用**其余**记录预测它的含义，统计真实命中/误命中。这暴露了闭式期望掩盖的长尾、平票与泛化难度。

| 要素 | 定义 |
| --- | --- |
| 查询 | 每条记录 = 一次"报故障码、不给机型"的真实查询；真实含义 = 该记录的 `name`（归一化）。 |
| 检索基线 | 多数投票：从**其余**同码记录中返回最常见含义（留一，剔除当前记录一票）。 |
| **弃答** | 留一后该码无其余记录 → 系统判"资料不足"而**弃答**（不算误命中，因为系统会说不知道，不是给错）。 |
| 误命中 | 在可预测样本中，返回含义 ≠ 真实含义。 |
| 机型澄清增益 | 无机型误命中 − 限定到该机型后（同 `code×model` 留一）的误命中。 |

> **诚实定位**：这是"多数投票检索基线"在留一下的 **empirical 泛化误差**，比闭式期望真实，但仍非端到端 LLM 系统实测（未跑语义检索/LLM）。它衡量的是检索层面对新查询的真实消歧表现。

---

## 3. 实验结果（留一实测）

**无机型基线**：可预测样本 8,747（76.2%），**弃答 2,729（23.8%）**；在可预测样本中**实测误命中率 = 51.7%**（全样本误答率 39.4%）。
> 对照：闭式期望仅 28.8%——留一实测显著更高，因为它暴露了长尾码留一后依据不足、平票、泛化误差等真实难度。**实测更严峻，也更可信。**

**限定机型后**：实测误命中降到 35.6%，但**弃答率飙到 83.8%**（`code×model` 组更稀疏，多数只有单条记录）——这是实测暴露的重要真相：细到机型时本地资料稀疏，是后续要补数据的方向。

### 验证 1 — 歧义熵预测实测误命中
| 相关性 | 数值 |
| --- | ---: |
| Pearson r | **0.856** |
| Spearman ρ | **0.922** |

| 熵区间 | 评估码数 | 查询占比 | 实测误命中 |
| --- | ---: | ---: | ---: |
| H = 0（单义，多记录） | 825 | 37.8% | **0.0%** |
| 0 < H ≤ 1 | 332 | 13.9% | 60.8% |
| 1 < H ≤ 2 | 314 | 17.8% | 88.0% |
| H > 2 | 263 | 30.5% | **90.6%** |

> 注：分桶为**有留一评估样本**（≥2 条记录）的码；单记录码归入弃答，不参与误命中统计。误命中随熵单调上升，Spearman 0.92 依然强相关。

### 验证 2 — 熵门控帕累托优于随机
相同追问预算下的**残余实测误命中率**（越低越好）：

| 追问预算 | AEG 熵门控 | 按频率门控 | 随机门控 | AEG 相对随机 ↓ |
| ---: | ---: | ---: | ---: | ---: |
| 5% | 46.9% | 47.5% | 49.4% | 5.1% |
| 10% | 42.4% | 43.1% | 46.7% | 9.1% |
| 20% | 33.5% | 34.1% | 41.2% | 18.9% |
| 30% | **24.4%** | 25.0% | 36.2% | **32.5%** |

> 熵门控稳定优于随机（30% 预算削减 32.5%），优势幅度小于闭式期望版（62.5%）——实测更保守但方向一致。频率门控仍是廉价近似，AEG 各预算领先。

### 验证 3 — 最优工作点
门控全部歧义码（`τ=0`）：**追问 62.2% 的查询 → 残余实测误命中 0%**（基线 51.7%）。追问率高于闭式版（47.4%），因实测下更多码被判为有风险。

### 验证 4（独立）— "追问机型"增益由熵驱动
`gain(c)` 由 `code×model` 联合分布决定，非 `H` 自函数：

| 相关性 | 数值 |
| --- | ---: |
| Pearson(H, gain) | **0.698** |
| Spearman(H, gain) | **0.724** |

| 熵区间 | 追问机型平均消除误命中 |
| --- | ---: |
| H = 0（单义） | **0.0%**（追问无用） |
| 0 < H ≤ 1 | 27.2% |
| 1 < H ≤ 2 | 59.5% |
| H > 2 | **84.5%** |

**高熵码（H>2）追问增益 84.5% ≈ 低熵歧义码（0<H≤1）27.2% 的 3.1 倍。** 单义码追问机型收益 0%。这条独立证据（相关性 0.72，较闭式版 0.97 温和但仍显著）说明门控优先级应由熵决定。

---

## 4. 结论

在 11,476 条真实记录上，用**留一法实测**（而非闭式期望）：

1. 歧义熵**预测实测误命中**（Spearman 0.92），是有效可解释的代理；
2. 熵门控**帕累托优于随机**（30% 预算削减实测误命中 32.5%）；
3. "追问机型"的实测增益与熵**独立相关**（Spearman 0.72），高熵码收益是低熵码 3 倍；
4. 明确工作点：**追问 62% 高风险查询 → 实测误命中 51.7%→0**。

**AEG 有效性在真实泛化设定下依然成立，数字更保守可信。**

---

## 5. 局限与诚实说明

- **实测 = 多数投票检索基线的留一泛化误差**，非端到端 LLM 系统实测；真实系统叠加语义检索与 LLM 组织后表现可能不同。
- **弃答不计误命中**：无机型时 23.8%、有机型时 83.8% 的查询因留一后资料不足而弃答。这既是保守（系统会说"资料不足"而非误答），也暴露了本地资料在细粒度上的稀疏——是扩充资料的明确方向。
- **含义粒度**用 `name` 精确匹配，可能高估歧义；语义聚类粒度属后续工作。
- **闭式期望 vs 留一实测**：前者 28.8% 基线、相关性 0.999，后者 51.7% 基线、相关性 0.92。实测更严峻但结论方向完全一致——本报告以实测为准。
