# 歧义熵门控 (AEG) — 创新点与有效性实验报告

> **Ambiguity-Entropy Gating**：用信息论对故障码消歧风险做**检索前**的可解释度量与主动门控。
>
> 数据：`风机故障码/fault-index.jsonl`，11,476 条有效故障记录（含 `code / brand / model / name`）。实验脚本：`scripts/aeg-ambiguity-entropy-experiment.py`，纯标准库、可复现。

---

## 1. 创新点

### 1.1 问题
同一数字故障码在不同机型下含义不同（同码异义）。现有做法——包括本系统的范围限定检索（L2）——都是**被动**的：检索时结合机型/上下文，**范围不明才提示**。缺点是无法回答"哪些码危险、危险到什么程度、值不值得为它打扰用户追问机型"。

### 1.2 方法：歧义熵门控 AEG
对每个故障码 `c`，基于它在语料中映射到的不同故障含义的概率分布 `p`，预先计算**香农歧义熵**：

```
H(c) = − Σ pᵢ · log₂ pᵢ
```

- `H(c) = 0`：单义码，直接检索作答，**不打扰用户**；
- `H(c) 越大`：跨机型歧义越强、误命中风险越高，**在检索前**就主动触发"追问机型"；
- 以阈值 `τ` 对 `H` 排序门控，得到"追问成本 ↔ 误命中"的可调工作点。

### 1.3 为什么创新
1. **从被动到主动**：把消歧从"检索后发现歧义"提前为"检索前用一个标量预测风险"。
2. **信息论可解释**：`H` 是单一、可解释、可设阈值的量，直接用于人机交互决策（该不该追问）。
3. **可量化门控**：以 `H` 排序，给出"用最小追问代价消除最多误命中"的帕累托前沿——现有规则式提示做不到这点。

## 2. 实验设计

| 要素 | 定义 |
| --- | --- |
| **含义粒度** | 归一化故障名称 `name`（去空格）。同码下不同 `name` 记为不同含义（严格定义）。 |
| **查询频率假设** | 用户查询某码的频率 ≈ 该码记录频率。 |
| **误命中模型** | 用户报"码"不带机型，系统返回该码**最常见含义**；用户真实含义按频率分布。单码期望误命中 `miss(c) = 1 − max(pᵢ)`。 |
| **歧义熵** | `H(c) = −Σ pᵢ log₂ pᵢ`。 |
| **门控** | 选一批码触发"追问机型"（不再误命中，但产生一次追问成本）。对比三种排序：**AEG（按 H 降序）/ 按记录频率 / 随机**。 |
| **独立增益** | `gain(c)=` 不带机型误命中 − 带机型平均误命中，即"追问机型"实际消除的误命中，由 `code×model` 联合分布决定。 |

**数据规模**：11,476 条记录，4,463 个唯一码，其中 **909 个歧义码（20.4%）**，单码最多 11 种含义。
> 注：20.4% 低于交底书的 35.3%，因为本实验用 `name` 精确匹配这一**更严格**的含义粒度；交底书按含义分组聚类。两者口径不同，结论方向一致。

## 3. 实验结果

**基线 A（无门控 / 纯按码检索）全局期望误命中率：`28.83%`**
基线 B（全部追问）：误命中 0%，但追问率 100%（打扰最大）。

### 验证 1 — 歧义熵是误命中的强预测信号
| 相关性 | 数值 |
| --- | ---: |
| Pearson r | **0.9805** |
| Spearman ρ | **0.9992** |

按熵分桶的平均误命中率单调上升：

| 熵区间 | 码数 | 查询占比 | 平均误命中 |
| --- | ---: | ---: | ---: |
| H = 0（单义） | 3,554 | 52.6% | **0.0%** |
| 0.5 < H ≤ 1.0 | 332 | 10.6% | 33.8% |
| 1.0 < H ≤ 2.0 | 314 | 13.6% | 59.3% |
| H > 2.0 | 263 | 23.2% | **74.1%** |

> `H` 与 `miss` 同源于分布 `p`，故此相关性含数学内在性——它证明的是"`H` 是 `miss` 的良好可门控代理"。真正独立的决策价值见验证 2、4。

### 验证 2 — 熵门控帕累托优于随机（决策价值）
相同追问预算下的**残余误命中率**（越低越好）：

| 追问预算 | AEG 熵门控 | 按频率门控 | 随机门控 | AEG 相对随机 ↓ |
| ---: | ---: | ---: | ---: | ---: |
| 5% | 24.80% | 25.00% | 27.41% | 9.5% |
| 10% | 20.97% | 21.31% | 26.12% | 19.7% |
| 20% | 13.71% | 13.96% | 22.95% | 40.3% |
| 30% | **7.40%** | 7.68% | 19.75% | **62.5%** |

> **AEG 显著优于随机门控**（30% 预算削减 62.5% 残余误命中）。按频率门控是廉价近似（高频码常伴高熵），但 AEG 在各预算下稳定领先——**熵是最优排序信号**。

### 验证 3 — 最优工作点
门控全部歧义码（`τ=0`）：**追问 47.4% 的查询 → 误命中降至 0%**（相对基线削减 100%）。实际部署可用更小预算取帕累托折中，例如 20% 追问即消除约 52% 误命中。

### 验证 4（独立）— "追问机型"的增益由熵驱动
`gain(c)` 由 `code×model` 联合分布决定，**非 `H` 的自函数**：

| 相关性 | 数值 |
| --- | ---: |
| Pearson(H, gain) | **0.9477** |
| Spearman(H, gain) | **0.9715** |

按熵分桶的"追问机型"平均增益：

| 熵区间 | 追问机型平均消除误命中 |
| --- | ---: |
| H = 0（单义） | **0.0%**（追问无用） |
| 0.5 < H ≤ 1.0 | 20.9% |
| 1.0 < H ≤ 2.0 | 49.8% |
| H > 2.0 | **73.1%** |

**高熵码（H>1.0）追问增益 64.5% ＝ 低熵歧义码（0<H≤1.0）20.9% 的 3 倍。**
> 这条独立证据说明：*该不该追问、优先问谁*，确实应由熵决定——对单义码追问机型毫无收益，对高熵码收益巨大。AEG 的门控优先级由此获得正当性，排除了循环论证。

---

## 4. 结论

在 11,476 条真实风电故障记录上：

1. **歧义熵能几乎完美预测误命中风险**（Spearman 0.999），是有效且可解释的代理指标；
2. **熵门控帕累托优于随机门控**（同预算削减误命中最多 62.5%），证明熵是有价值的决策排序信号；
3. **"追问机型"的实际增益与熵独立强相关**（Spearman 0.97），高熵码收益是低熵码的 3 倍，为门控优先级提供了非自相关的正当性；
4. 存在明确工作点：**只对约半数（高风险）查询追问一次机型，即可将误命中从 28.8% 降至 ~0**。

**AEG 有效性成立。** 它把同码异义消歧从被动补救升级为信息论驱动的、可解释、可调节的主动风控。

---

## 5. 局限与诚实说明

- **误命中率为理论期望值**，基于"返回最频含义"策略与"查询频率≈记录频率"假设，非真实用户点击实测；真实值受用户查询分布影响。
- **含义粒度**用 `name` 精确匹配，可能把同义不同写法误判为不同含义（高估歧义），也可能把细分含义合并；更稳健的粒度可用语义聚类，属后续工作。
- **AEG 与按频率门控差距较小**（熵略优），说明频率是廉价近似；熵的额外价值在于其信息论可解释性与可设阈值性。
- 单义码（52.6% 查询）在本模型中误命中恒为 0，实际仍可能因资料本身错误或跨风场差异出错，本实验不覆盖。
